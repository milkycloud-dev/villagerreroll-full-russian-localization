## English

### Overview

This repository provides clean, standalone Russian localization files for **VillagerReroll v2.0**.
It contains only configuration and text files to respect original author licensing and copyright requirements.

### Files

- `README.md`: Documentation and instructions for using the localized trade item.

### Installation

1. Upstream VillagerReroll hardcodes trade items in bytecode.
2. Use the pre-built `villager-reroll-2.0-RU.jar` in your server plugins folder.

## Русский

### Описание

Репозиторий содержит чистые файлы русской локализации для **VillagerReroll v2.0**.
В состав включены исключительно файлы конфигурации и переводов, без бинарных сборок, с соблюдением требований лицензий авторов.

### Файлы

- `README.md`: Документация и инструкция по установке русифицированного предмета сделки.

### Установка

1. В оригинальном плагине текст сделок зашит в байткод.
2. Поместите готовую сборку `villager-reroll-2.0-RU.jar` в папку `plugins` сервера.
